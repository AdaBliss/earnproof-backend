KEY COMPONENTS
==============

DnsPinningService (New)
  ├─ resolveAndPin(hostname, resolveFn?) -> Promise<DnsPinningResult>
  │  └─ Resolves hostname to public IP, validates against SSRF policy
  └─ shouldReResolve(record, ttlSeconds?) -> boolean
     └─ Determines if cached resolution should be refreshed

WebhookDeliveryService (Modified)
  ├─ Constructor: Inject DnsPinningService
  └─ sendSignedRequest(): 
     ├─ Call dnsPinning.resolveAndPin() before fetch
     ├─ Pin connection to resolved IP
     ├─ Maintain hostname in Host header
     └─ Return DNS metadata in SignedRequestOutcome

WebhookDelivery Model (Modified)
  ├─ dnsPinned: boolean (tracks if DNS pinning used)
  ├─ dnsResolutionMs: int (tracks resolution duration)
  └─ dnsAddressCount: int (tracks number of addresses)
